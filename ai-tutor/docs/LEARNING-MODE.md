# 每日学习模式

## 最终完整每日流程 (2-3小时/天)

### STEP 0 复习抽查 (10min)
- 速问速答：抽查之前知识点（间隔重复：Day1→Day2隔1天→Day4隔3天→Day7全面复习）
- 面试模拟：随机抽一题，用户用费曼学习法口头回答

### STEP 1 新知识讲解 (20min)
- 类比建立直觉 → 流程图理解原理 → 源码验证
- 每个知识点标注：在知识检索师项目的哪个位置用到

### STEP 2 手写补全 (40min)
- 给用户注释好的骨架代码（已验证可编译运行，核心逻辑用 TODO 注释掉）
- TODO 格式：// TODO [W1D2-任务1]: 实现流式对话 // 提示：返回 Flux<String>，用 .stream()
- 用户手写补全 → 运行验证 → 不会就停住深讲
- 所有代码都在 ai-tutor 项目中，随天数生长

### STEP 3 审查校准 (15min)
- 人工审查：逻辑、风格、安全、设计模式
- Codex AI 审查：规范检查、安全扫描（用户对比两种审查结果学习）
- 不懂就停，深讲到底，不带问号往前走

### STEP 4 面试五连问 (10min)
- ① 是什么（一句话定义）
- ② 解决什么问题（没有它之前怎么做的）
- ③ 核心原理（用类比 + 流程图）
- ④ 对比方案（vs XXX 什么时候用哪个）
- ⑤ 踩过什么坑（生产环境常见问题）
- 用户口头回答，AI 校准

### STEP 5 Git 提交 + 回顾 (10min)
- git diff 看今天改了什么
- Commit Message 规范：[W1D2] feat: 实现流式对话接口
- git add -p 分块提交（学精细化管理）
- Code Review 闭环：人审 → AI审 → 用户对比

### STEP 6 速记卡 + 今日产出 (5min)
- 5-7 个关键词 + 一句话解释
- 写入 docs/daily/YYYY-MM-DD.md

## 三线合一原则

`
ai-tutor GitHub 公开仓库
    ├── 学知识：每个概念理解原理 + 手写验证
    ├── 面面试：五连问对答如流，commit 历史展示学习轨迹
    └── 出项目：每行代码都在最终工程里，没有一次性 Demo
`

## 项目代码规则
- 搭骨架 → 编译验证 → 注释核心逻辑 → 用户手写补全
- 与最终项目无关的代码不写入工程
- Git log 可追溯每天学了什么、写了什么

## 复习节奏
- 间隔1天：抽查前一天
- 间隔3天：抽查3天前
- 每7天：周六大复习
- 形式：速问速答 / 填空补全 / 面试模拟
