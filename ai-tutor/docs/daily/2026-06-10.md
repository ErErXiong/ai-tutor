# Day 1 速记卡 — 2026-06-10

## 关键词速记

| 关键词 | 一句话 |
|--------|--------|
| ChatModel | 底层无状态接口，手动拼历史，每次 call() 独立 |
| ChatClient | 高层封装，Builder模式，Advisor 链自动管记忆/RAG/日志 |
| Prompt | = List\<Message\> + 模型参数，发给 LLM 的完整请求 |
| Message | System(规则) / User(用户话) / Assistant(AI回复) 三种角色 |
| Advisor | 对话的 AOP 环绕通知，aroundCall 前置注入/后置保存 |
| ChatMemory | 存对话历史，LastN 截断 / SUMMARIZE 摘要压缩 |
| aroundCall | Advisor 核心方法，包裹 ChatModel 调用，前后做手脚 |

## 今日产出

## 面试五连问（今日掌握）

1. 是什么？ChatModel 是大模型的无状态底层接口
2. 解决什么？ChatClient 用 Advisor 链自动管理记忆，不用手动拼历史
3. 原理？aroundCall 前置注入历史 → ChatModel 调用 → 后置保存对话
4. 对比？ChatModel 裸调用 vs ChatClient 带 Advisor；单次用前者，多轮用后者
5. 踩坑？Memory 无限增长用 LastN 截断；Token 超限用 SUMMARIZE 压缩
